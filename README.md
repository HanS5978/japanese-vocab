# 我的日文單字本

以 JLPT N4 為目標的 1243 個日文單字，分成三條路線：N5 基礎、N4 核心、生活與旅遊。每天從三條路線各抽 2 個，共 6 個新字。
每個字都有漢字、讀音、詞性、中文、發音、例句與翻譯，並有字卡學習、間隔複習和讀音填空測驗（可打假名或羅馬拼音）。

## 使用方式
直接用瀏覽器打開 `index.html` 即可，不需要安裝任何東西。

## 檔案
- `index.html`：程式本體
- `words.js`：單字資料
- `manifest.webmanifest`、`icon-*.png`：加到主畫面用的名稱與圖示

## 注意
- 發音使用瀏覽器內建的日文語音（Chrome、Safari、Edge 都支援；iPhone 可在「朗讀內容」下載日文聲音，例如 Kyoko）。
- 放在 GitHub Pages 時，學習進度存在手機瀏覽器裡（不會跨裝置同步）。
- 每天學完會顯示一組 4 位數「進度密碼」，換手機或資料不見時可輸入密碼回復進度。
- 「新增與設定」頁的「完整進度備份」可以保存包含複習狀態、收藏、自訂單字的完整進度。
